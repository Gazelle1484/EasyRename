# Codex段階的開発フロー

## STEP 1: 要件整理（仕様固定）
目的：
- Android33移行で動作するandroidアプリを作成する。

指示内容：
- アプリの目的  
  - ファイルのRenameの手順を簡略化する。 
  - Renameしたい、Rename先のファイル名が正規表現になって記述してあるcsvの読み込み（例：A1-1_*と書いておくと、先頭にA1-1をつけてRenameする） 
- 必要な機能一覧：
  - androidスマホ内のストレージの読み込み
  - CSVファイルの読み込み
  - 内部ストレージに格納されたファイルのRenameの実行（必要であれば実行権限を付与）
- 非機能要件（性能・UI・制約）
  - GUI上でRenameしたいファイルが格納されたディレクトリを選択する。（ディレクトリ選択画面）
  - RenameにはGUIを用いる（Renameマッチング画面）。画面左側にRename前のスマホストレージ内のファイルリスト、右側にRename先ファイル名リストを表示する。左右からひとつづつタップして選択すると、決定ボタンが有効になり、Renameが実行される。

出力させるもの：
- 機能一覧
- 画面一覧
- データ構造
- 不明点・前提
